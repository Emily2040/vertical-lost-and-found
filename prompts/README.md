## English

Copy the full prompt block from your preferred language into an agent that can actually use Gemini 4, Nano Banana, Blender, Three.js and browser/capture tools. Each version gives the same production requirements. Capability checks, material generation, gameplay, testing and the one-minute recording are part of the brief.

These prompts consolidate the original concept and the requirements developed during production. They are not a verbatim session transcript or a claim that one prompt produced the repository unchanged. The [original English brief](original-brief.en.txt) is preserved separately. Model versions, generated images, iteration and hardware can change the result. To run this exact game, use the committed source and assets with the [setup commands](../README.md#run-locally).

The photographic look is a target. This build has working tested routes, but its visual target remains unmet; full motion, listening and audiovisual sync are unreviewed. See [verification and limits](../docs/verification.md).

本项目以照片级真实感为视觉目标。当前版本已能按测试路线通关，但画面尚未达到目标，完整的动态画面审看、音频试听和声画同步检查也尚未进行。详情见[验证结果与局限](../docs/verification.md)。

## 한국어

원하는 언어의 프롬프트를 열고 코드 블록 전체를 복사해 Gemini 4, Nano Banana, Blender, Three.js와 브라우저·녹화 도구를 실제로 사용할 수 있는 에이전트에 입력하세요. 네 언어판의 제작 요구 사항은 같습니다. 도구의 실제 사용 가능 여부 확인, 머티리얼 생성, 게임플레이, 테스트, 1분 시연 영상 녹화까지 포함합니다.

이 프롬프트는 최초의 구상과 제작 과정에서 구체화한 요구 사항을 정리한 것입니다. 전체 대화를 그대로 옮긴 기록이 아니며, 프롬프트 한 번으로 이 저장소의 내용이 수정 없이 완성됐다는 뜻도 아닙니다. [최초 영문 제작 지침](original-brief.en.txt)은 별도로 보존했습니다. 모델 버전, 생성된 이미지, 수정 과정과 하드웨어에 따라 결과가 달라집니다. 공개된 버전을 그대로 실행하려면 저장소에 포함된 소스와 에셋을 사용하고 [한국어 안내](../README.ko.md)를 따르세요.

사진처럼 사실적인 표현을 목표로 했지만, 현재 빌드는 아직 그 수준에 이르지 못했습니다. 테스트한 경로는 완주할 수 있으며, 영상 전체의 움직임, 전 구간 청취, 음향과 화면의 동기화는 아직 검토하지 않았습니다. 자세한 내용은 [검증 결과와 한계](../docs/verification.md)를 참고하세요.

## 日本語

使いたい言語のプロンプトを開き、コードブロック全体をコピーして、Gemini 4、Nano Banana、Blender、Three.js、ブラウザ操作・収録ツールを実際に使えるエージェントに渡してください。4 言語とも制作要件は同じです。ツールの確認、マテリアル生成、ゲームプレイ、テスト、1 分間のデモ動画の収録まで含みます。

このプロンプトは、当初の構想と制作中に具体化した要件をまとめたものです。制作時のやり取りをそのまま書き起こしたものではなく、一度の指示だけでこのリポジトリの内容が完成したという意味でもありません。[最初の英語プロンプト](original-brief.en.txt)は別途保存しています。モデルのバージョン、生成画像、修正の過程、ハードウェアによって結果は変わります。この実装をそのまま動かすには、リポジトリに収録したソースコードとアセットを使い、[日本語の手順](../README.ja.md)に従ってください。

写真のような質感は、現時点ではまだ目標です。テスト済みのルートはクリアできますが、映像表現は目標に届いていません。動画全編の動き、音の試聴、映像と音声の同期についても、まだ確認を行っていません。詳細は[検証結果と制約](../docs/verification.md)を参照してください。
