**Google Antigravity 上の Gemini 4** で制作しました。テクスチャ画像の生成に Nano Banana、3D 制作に Blender、ゲームの描画に Three.js を使用しています。

鉄道の保管庫を登っていくパズルゲームです。引き出しをレールに沿って引き出し、所定の位置で固定し、荷物を動かして昇降機を作動させます。最初の引き出しから屋上庭園まで、3 つのステージを進んでいきます。

これはレビュー用に公開する開発版です。保存済みの操作ルートでは仕掛けが正常に動作することを確認していますが、キャラクター、繰り返し配置された収納棚、ライティングは、目標とする写実的な表現にまだ届いていません。動画全編の動き、音の試聴、映像と音声の同期については、まだ確認を行っていません。

## 制作用プロンプト

使いたい言語のプロンプト全文をコピーしてください：[English](prompts/en.md) · [简体中文](prompts/zh-CN.md) · [한국어](prompts/ko.md) · [日本語](prompts/ja.md)。

Gemini 4、Nano Banana、Blender、Three.js を使ってこのゲームを作るための要件を、同じ内容で 4 言語にまとめています。このプロジェクトは複数回の修正を経て制作したものです。プロンプトだけで、同一のアセットや結果が得られるとは限りません。この実装をそのまま動かすには、以下の手順でリポジトリに収録したソースコードとアセットを使用してください。[プロンプトガイド](prompts/README.md)には、最初に使用した英語の制作指示と、目標とした映像表現と現在の実装との差についても記載しています。

## ローカルで起動する

Node.js 20 以降を使用してください。プレイに API キーは不要です。

```sh
npm ci
npm run dev
```

Vite が表示するローカル URL を開いてください。本番用ビルドを確認する場合は、次のコマンドを実行します。

```sh
npm run build
npm run preview
```

## 操作方法

| キー | 操作 |
|---|---|
| W A S D | 移動 |
| Space | ジャンプ |
| Tab / Shift + Tab | 手の届く仕掛け・荷物を選択 |
| Q / E | 選択したレールを押す・引く |
| L | レールの固定位置でロック・解除 |
| H | 荷物ハッチを開閉 |
| F | 荷物を持ち上げる・置く・送り出す |
| G | 最後の引き出しを内側から開く |
| R | 直前のチェックポイントに戻る |

選択中の対象に応じた操作ヒントをゲーム内に表示します。音声は操作後に有効になり、ミュートもできます。

## 検証と編集

```sh
npm run verify
```

アプリをビルドし、仕掛けに関する 77 項目のチェックと、通常の操作で進む 4 つのルートを実行します。テスト結果は `.run/verification/` に保存されます。人がプレイして難易度を評価するテストは、これとは別に必要です。

編集可能な `.blend` ファイルは `assets/blender/` にあります。形状を生成するスクリプト、生成直後のテクスチャ画像、マテリアルの準備スクリプト、シーンの状態を保存する記録も収録しています。[制作手順](docs/authoring.md)、[録画方法](docs/recording.md)、[検証内容](docs/verification.md)を参照してください。

1 分間の紹介動画は、1920 × 1080、ステレオ音声付きで、シミュレーションから取得した 3,600 サンプルを収録しています。実際のゲーム操作を使ってオフラインで収録したものです。別途行ったリプレイのベンチマークでは、テスト機で毎秒 37.33 回の描画を計測しました。この数値は、実際のプレイ全体のフレームレートを示すものではありません。

このゲームでは、キャラクターの移動と接地を扱う制約付きのコントローラーと、解析的に動きを計算する仕掛けを使用しています。荷物の持ち上げと設置は、離散的な状態変更として処理します。汎用の剛体シミュレーターではありません。
