## プロンプト

```text
廃駅の大ホールにそびえる巨大な引き出しの壁を舞台に、登攀パズルゲームを構築してください。

私の足元で引き出しが勢いよく飛び出す場面から始めます。中から転がり出た荷物が受け皿トレイに落ち、その重みでカウンターウェイトが引かれ、私がジャンプする瞬間に合わせて次の引き出しが開きます。

仕掛けの荷重を組み替えながら登れるようにしてください。レールに沿って引き出しを引き、目に見えるノッチ（刻み目）でラッチを掛け、連結されたトレイの間で重みのある荷物を移し替えます。引き出しは私の使い方次第で、足場にも、昇降機にも、カウンターウェイトにもなります。

壁には一目でそれと分かる遺失物を詰めてください。トランク、丸めた絨毯、箱入りの楽器、陶器の包みなどです。レール、ローラー、むき出しのワイヤー、移送シュートは Blender でモデリングしてください。使い込まれた漆塗り、鞄の帆布、擦り切れた裏地のテクスチャには Nano Banana を使用します。

第1ステージでは3つの引き出しで階段を作ります。第2ステージでは連動する引き出しの間で重いケースを1つ移し、戻り道を残したままリフトを上昇させます。第3ステージでは、荷重の移し替え、動く足場、タイミングを合わせたジャンプを連続させながら上へと登ります。

各オブジェクトの同一性と質量を保ってください。私の体重はロックされていない足場に実際に作用し、ラッチは本物のノッチに噛み合わなければなりません。

最後は最後の引き出しを内側から開けて締めくくります。巨大な収納壁の向こうに陽光が差し込み、屋上庭園が姿を現します。この一連の進行を、躍動感のある1分間のショーケース映像に収めてください。
```

詳細な制作用ブリーフ：[English](prompts/en.md) · [简体中文](prompts/zh-CN.md) · [日本語](prompts/ja.md) · [한국어](prompts/ko.md) · [プロンプトガイド](prompts/README.md)。

## 概要

**Google Antigravity 上の Gemini 4** を使用し、テクスチャ画像の生成に Nano Banana、3D 制作に Blender、実行環境に Three.js を用いて制作しました。

鉄道の遺失物保管庫を舞台にした登攀パズルです。引き出しをレールに沿って引き出して固定し、荷物を動かしてリフトを動かします。3 つのステージを経て、最初の引き出しから屋上庭園へと登っていきます。

これはレビュー用に共有している開発ビルドです。保存されたルートで仕掛けが動くことは確認していますが、キャラクター、反復する棚の造形、ライティングはまだ目標とした写真のような質感には届いていません。通常速度での全編の映像確認、試聴、映像と音声の同期確認は未実施です。このプロジェクトは複数回の修正を経て制作したものであり、プロンプトだけで同一のアセットや結果が得られるとは限りません。この実装をそのまま動かすには、以下の手順でリポジトリに収録したソースコードとアセットを使用してください。

## ローカルで起動する

Node.js 20 以降を使用してください。プレイに API キーは不要です。

```sh
npm ci
npm run dev
```

Vite が表示するローカル URL を開いてください。本番用ビルドを確認する場合は、次のコマンドを実行します。

```sh
npm run build
npm run preview
```

## 操作方法

| キー | 操作 |
|---|---|
| W A S D | 移動 |
| Space | ジャンプ |
| Tab / Shift + Tab | 手の届く仕掛け・荷物を選択 |
| Q / E | 選択したレールを押す・引く |
| L | レールの固定位置でロック・解除 |
| H | 荷物ハッチを開閉 |
| F | 荷物を持ち上げる・置く・送り出す |
| G | 最後の引き出しを内側から開く |
| R | 直前のチェックポイントに戻る |

選択中の対象に応じた操作ヒントをゲーム内に表示します。音声は操作後に有効になり、ミュートもできます。

## 検証と編集

```sh
npm run verify
```

アプリをビルドし、仕掛けに関する 77 項目のチェックと、通常の操作で進む 4 つのルートを実行します。テスト結果は `.run/verification/` に保存されます。人がプレイして難易度を評価するテストは、これとは別に必要です。

編集可能な `.blend` ファイルは `assets/blender/` にあります。形状を生成するスクリプト、生成直後のテクスチャ画像、マテリアルの準備スクリプト、シーンの状態を保存する記録も収録しています。[制作手順](docs/authoring.md)、[録画方法](docs/recording.md)、[検証内容](docs/verification.md)を参照してください。

1 分間の紹介動画は、1920 × 1080、ステレオ音声付きで、シミュレーションから取得した 3,600 サンプルを収録しています。実際のゲーム操作を使ってオフラインで収録したものです。別途行ったリプレイのベンチマークでは、テスト機で毎秒 37.33 回の描画を計測しました。この数値は、実際のプレイ全体のフレームレートを示すものではありません。

このゲームでは、キャラクターの移動と接地を扱う制約付きのコントローラーと、解析的に動きを計算する仕掛けを使用しています。荷物の持ち上げと設置は、離散的な状態変更として処理します。汎用の剛体シミュレーターではありません。
