**Google Antigravity의 Gemini 4**로 제작했으며, Nano Banana로 생성한 텍스처 이미지와 Blender, Three.js를 사용했습니다.

철도 기록보관소를 배경으로 한 등반 퍼즐 게임입니다. 서랍을 레일을 따라 당겨 고정하고, 짐을 옮겨 승강기를 움직입니다. 첫 서랍에서 시작해 세 단계를 거치면 옥상 정원에 도착합니다.

피드백을 받기 위해 공개한 개발 버전입니다. 게임의 동작은 저장된 플레이 경로로 확인했습니다. 다만 캐릭터, 반복 배치된 수납장, 조명은 사진처럼 사실적인 표현이라는 목표에 아직 미치지 못합니다. 영상 전체의 움직임, 실제 청취 품질, 음향과 화면의 동기화는 아직 검토하지 않았습니다.

## 제작 프롬프트

원하는 언어의 전체 프롬프트를 복사해 사용하세요. [English](prompts/en.md) · [简体中文](prompts/zh-CN.md) · [한국어](prompts/ko.md) · [日本語](prompts/ja.md)

각 언어판은 Gemini 4, Nano Banana, Blender, Three.js로 이 게임을 다시 만들기 위한 통합 제작 지침이며, 요구 사항은 같습니다. 이 프로젝트는 여러 차례 수정을 거쳤습니다. 프롬프트만으로 동일한 에셋이나 결과가 생성된다고 보장할 수는 없습니다. 지금 공개된 구현을 그대로 실행하려면 아래 안내에 따라 저장소에 포함된 소스와 에셋을 사용하세요. [프롬프트 안내](prompts/README.md)에는 최초의 영문 제작 지침과 함께, 목표로 삼은 시각적 품질과 현재 빌드의 차이를 설명했습니다.

## 로컬에서 실행하기

Node.js 20 이상이 필요합니다. 플레이에는 API 키가 필요하지 않습니다.

```sh
npm ci
npm run dev
```

Vite가 출력하는 로컬 주소를 브라우저에서 여세요. 프로덕션 빌드를 실행하려면 다음 명령을 사용합니다.

```sh
npm run build
npm run preview
```

## 조작 방법

| 키 | 동작 |
|---|---|
| W A S D | 이동 |
| Space | 점프 |
| Tab / Shift + Tab | 손이 닿는 장치 / 화물 선택 |
| Q / E | 선택한 레일 밀기 / 당기기 |
| L | 레일의 고정 홈 잠금 / 해제 |
| H | 화물 투입구 열기 / 닫기 |
| F | 화물 들기 / 놓기 / 보내기 |
| G | 마지막 서랍을 안에서 열기 |
| R | 마지막 체크포인트 상태 복원 |

게임 내 안내에서 선택한 대상의 조작 방법을 확인할 수 있습니다. 한 번 조작하면 소리가 켜지며, 음소거할 수 있습니다.

## 검증과 수정

```sh
npm run verify
```

이 명령은 앱을 빌드한 뒤 게임 동작 검사 77개와 일반 조작으로 진행하는 플레이 경로 4개를 검증합니다. 검사 결과는 `.run/verification/`에 저장됩니다. 사람이 직접 플레이하며 난이도를 평가하는 과정은 별도로 필요합니다.

수정 가능한 `.blend` 파일은 `assets/blender/`에 있습니다. 지오메트리 생성 스크립트, 생성된 텍스처 원본, 머티리얼 준비 스크립트, 장면 상태를 보존하는 기록 파일도 포함되어 있습니다. [제작 안내](docs/authoring.md), [녹화 안내](docs/recording.md), [검증 안내](docs/verification.md)를 참고하세요.

시연 영상은 1분 분량이며, 시뮬레이션 상태를 3,600회 샘플링해 1920 × 1080 해상도와 스테레오 음향으로 녹화했습니다. 실제 게임 조작을 재생하는 방식으로 오프라인 캡처했습니다. 별도의 리플레이 벤치마크에서는 테스트한 기기에서 초당 37.33회 렌더링을 기록했습니다. 이는 실제 플레이 전체의 FPS를 측정한 결과는 아닙니다.

이 프로젝트는 제약 조건 기반의 캐릭터·지지면 컨트롤러와 수식으로 동작을 계산하는 장치를 사용합니다. 화물 집기와 놓기는 정해진 상태 전환으로 처리합니다. 범용 강체 시뮬레이터는 아닙니다.
